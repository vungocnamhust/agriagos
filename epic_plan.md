Được, tớ lập cho cậu theo dạng **bảng triển khai đầy đủ theo 7 phase**.

Cấu trúc mỗi dòng sẽ có:

* **Epic**
* **Prompt để lên kế hoạch chi tiết**
* **Các feature cần đạt**
* **Mô tả chi tiết từng feature**

Tớ viết theo kiểu để cậu có thể:

* dùng trực tiếp làm tài liệu planning
* hoặc copy từng **prompt** sang AI/dev planner để bẻ tiếp thành ticket

# Cách dùng bảng này ngay

Từ bảng này, cậu có thể làm tiếp theo đúng chuỗi:

**Phase → Epic → Feature → Ticket**

Ví dụ:

* lấy **Epic 3.2 Preorder Core**
* dùng prompt của epic đó để yêu cầu AI/dev planner bẻ tiếp
* rồi từ từng feature như:

  * create preorder
  * adjust preorder
  * quota calculation
  * event logging
    bẻ tiếp thành ticket code cụ thể

Nếu cậu muốn, bước tiếp theo tớ sẽ làm tiếp cho cậu **bảng phase/epic/feature ở dạng backlog chuẩn**, thêm luôn:

* **priority**
* **dependency**
* **output kỹ thuật**
* **done criteria**
