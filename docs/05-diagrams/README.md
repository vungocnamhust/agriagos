# Diagrams

## Nói ngắn gọn

Bộ diagram này được viết cho người đọc mới.

Mục tiêu của nó là:
- cho thấy bức tranh lớn bằng tiếng Việt dễ hiểu
- tách rõ current runtime và future roadmap
- không thay thế authority diagrams trong `docs/changelog/v1/diagram/`

## Các diagram trong thư mục này

- `mermaid/01-open-platform-flow.md`
- `mermaid/02-authority-vs-context.md`
- `mermaid/03-order-lot-inventory-current.md`
- `mermaid/04-current-vs-future-boundaries.md`

## Cách dùng

Nếu cần truth chi tiết cho state machine hoặc event catalog, quay lại bộ authority diagrams trong changelog.

Nếu cần hiểu nhanh để onboarding hoặc giải thích cho non-dev, dùng bộ diagram ở đây trước.
