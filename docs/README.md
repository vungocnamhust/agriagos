# AgriOS Docs

Đây là lớp tài liệu dễ đọc cho founder, dev, product, ops và người mới.

Nguyên tắc đọc nhanh:
- Bắt đầu từ `docs/00-start-here/README.md`.
- Xem `docs/02-current-runtime/` nếu muốn biết code đang chạy gì.
- Xem `docs/07-roadmap/current-vs-future.md` nếu muốn biết cái gì đã có, cái gì mới là định hướng.

Authority gốc cho kiến trúc và contract vẫn nằm ở bộ changelog:
- `docs/changelog/v1/architecture/00-source-of-truth-registry.md`
- `docs/changelog/v1/divergence-ledger.md`

Lớp docs này không thay thế authority docs. Nó có nhiệm vụ:
- giải thích lại bằng tiếng Việt dễ hiểu
- gom thứ tự đọc hợp lý
- tách rõ runtime hiện tại và roadmap tương lai
- giảm việc người mới bị lạc trong thuật ngữ tiếng Anh
