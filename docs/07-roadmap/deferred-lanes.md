# Deferred Lanes

## Nói ngắn gọn

Đây là các lane nên được xem là chưa ship, dù đã có nói tới trong kiến trúc hoặc roadmap.

## Danh sách deferred lanes

- full `PermissionGrant` runtime engine
- field-level masking
- delegated permission runtime đầy đủ
- org or project aware ABAC đầy đủ
- tool gateway cho agent
- agent session scope
- canonical user account aggregate
- communication binding runtime lane có authority semantics

## Cách ghi tài liệu cho deferred lanes

- luôn viết dưới nhãn future, deferred hoặc planned
- không đưa vào phần current runtime
- không vẽ diagram current như thể lane đó đang chạy
