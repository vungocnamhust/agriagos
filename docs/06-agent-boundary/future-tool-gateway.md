# Future Tool Gateway

## Nói ngắn gọn

`Tool Gateway` là roadmap lane, chưa phải runtime đang ship.

## Mục tiêu tương lai

- cho agent gọi tool theo hợp đồng rõ ràng
- gắn authority checks cho từng tool
- ghi audit rõ tool nào được gọi bởi ai và với quyền gì
- ngăn agent dùng một tool quá rộng kiểu “raw shell vào core data”

## Điều chưa có trong runtime hiện tại

- tool permission matrix đầy đủ
- policy engine theo tool
- session scope cho agent
- delegated tool execution runtime hoàn chỉnh

## Cách nói đúng hiện tại

Không viết rằng AgriOS đã có tool gateway runtime. Chỉ nên nói hệ thống định hướng đi về phía đó.
